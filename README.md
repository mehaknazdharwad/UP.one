# UP.one

A clean, bilingual dashboard for managing electrical grievances in Uttar Pradesh.

## Dashboard features

- **Overview:** Complaint totals, seven-day SLA tracking, critical cases, trends, a recurring-issues pie chart, and district distribution.
- **Complaints:** One searchable list with creation dates, locations, priorities, assigned officers, and status filters.
- **Officers:** Workload, overdue assignments, and completed cases for each officer.
- **Resolution:** Repair photo and resolution note required to mark a complaint solved, with a complete activity history.
- **Lifecycle:** New, assigned, in progress, resolved, closed, reopened, and escalated complaints.
- **Accessibility:** English and Hindi, responsive layouts, and CSV export.

Includes 15 sample complaints. UP.one is a demonstration, not an official government service.
